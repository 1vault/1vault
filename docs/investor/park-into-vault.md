# Park into a vault (investor)

Investors park SOL into a **public** vault and ride the shared book. You do **not** sign the strategist’s trades.

## Before you park

| Check | Why |
|-------|-----|
| Extension installed + unlocked | [Install](/extension/install) / [Wallet](/extension/wallet-keyring) |
| Vault is **Active** | Closed vaults do not take new parks |
| You understand share-weight close | [Concepts](/guide/concepts#close-by-share-weight) |

---

## Step-by-step

1. Bottom nav → **Discover**  
2. Search by name, vault, or trader - or scroll the list  
3. Tap a vault card to open [Vault detail](/extension/vault-detail)  
4. Review NAV, status, trader, verified badge if any  
5. Tap **Park SOL**  
6. Enter amount (presets / Max available)  
7. Tap **Park** and approve signatures  
8. Success: **SOL parked** - you now hold shares  

Park screen details: [Park SOL](/extension/park-and-capital).

---

## What you get

| You get | Meaning |
|---------|---------|
| Vault **shares** | Your weight in the shared book |
| Exposure to results | Value moves with the vault |
| Optional [TP / SL](/investor/tp-sl) | Risk controls when the UI shows them |
| Ability to withdraw later | [Withdraw](/investor/withdraw) |
| Close payout if strategist closes | By **share weight**, not 50/50 |

---

## What you do not do

- Pick every token the strategist trades  
- Co-sign market transactions  
- Unlock the strategist’s $1VAULTS  
- Control Close on someone else’s vault  

---

## Tips

- Start small while you learn the UI  
- Prefer verified traders when X is linked  
- Watch **Incoming** on capital if numbers look mid-settlement  
- Read [Safety & custody](/guide/safety-and-custody) before sizing up  

## Common issues

| Issue | Fix |
|-------|-----|
| Cannot park | Vault not Active, or wallet locked |
| Insufficient balance | Lower amount / add SOL |
| No vaults on Discover | Refresh; broaden search |
