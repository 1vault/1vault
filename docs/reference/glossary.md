# Glossary

| Term | Definition |
|------|------------|
| **1Vault** | Pooled Solana trading vault product - Capital in Motion |
| **$1VAULTS** | $1VAULTS token; **1,000,000** locked per vault on create |
| **Active vault** | Vault that still allows park / trade (not Closed) |
| **Capital pipeline** | Home estimate: committed / incoming / mandated / projected |
| **Claim fees** | Strategist collects accrued performance fees ([guide](/extension/claim-fees)) |
| **Close** | Wind down vault; payout by share weight; unlock $1VAULTS |
| **High-water mark (HWM)** | Highest share-price band already charged performance fee; fee only on new highs |
| **Committed** | Already parked on-chain |
| **Strategist** | Vault operator - creates vault, locks $1VAULTS, parks, signs trades, closes, unlocks $1VAULTS |
| **Discover** | Public vault list |
| **Incoming** | Parks still settling |
| **Keyring** | Encrypted local wallet storage in the extension |
| **Mandated** | Amount you are expected to park |
| **Park** | Deposit SOL for vault shares |
| **Pooled** | Shared book mode |
| **Projected** | Estimated value including incoming |
| **Investor** | Parks into a public vault and rides; does not sign vault swaps |
| **Ride** | Stay in the book while the strategist trades |
| **Shares** | Ownership units of the vault book |
| **Share weight** | Close / withdraw math proportional to shares |
| **Sliced** | Future mode for per-investor early exits |
| **TP / SL** | Investor take-profit / stop-loss settings ([guide](/investor/tp-sl)) |
