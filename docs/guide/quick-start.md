# Quick start

From zero to a live vault. Follow the path that matches your role.

Not sure who you are? **Strategist** runs the vault and trades. **Investor** parks into someone else’s vault and rides. Full breakdown: [Roles](/guide/roles).

## What you need

| Item | Why |
|------|-----|
| Chrome | Runs the 1Vault extension |
| SOL | Network fees + park capital |
| **$1VAULTS** (strategist only) | **1,000,000 $1VAULTS** locked when you create a vault |

Install first: [Install the extension](/extension/install).

---

## Strategist path (create + trade)

### 1. Set up your wallet

1. Open the side panel  
2. Import your Solana secret key and set a password (**Create keyring**)  
3. **Unlock** with that password  

Details: [Wallet & keyring](/extension/wallet-keyring).

### 2. Create a vault and lock $1VAULTS

1. On **Home**, tap **Create**  
2. Walk the wizard: **Name → X (optional) → Terms → $1VAULTS licence → Create vault**  
3. If you are short on $1VAULTS, use **Go to Swap**, then **Refresh balance**  
4. Confirm the lock (tokens return **in full** when the vault closes)  

Full walkthrough: [Create vault & lock $1VAULTS](/extension/create-vault-and-lock).

### 3. Park (if you need more size)

Create already parks your **initial** SOL. To add more:

1. Keep the vault selected on Home  
2. Tap **Park**  
3. Enter amount → **Park**  

You must have parked shares before you can trade. Details: [Park SOL](/extension/park-and-capital).

### 4. Trade

1. Bottom nav → **Trade**, or Home → **Trade**  
2. **Open position** (or use the [GMGN pill](/extension/instant-trade-terminals))  
3. When done, **Exit** open positions on Trade  

Details: [Trade & positions](/extension/trade-and-positions).

### 5. Close and unlock $1VAULTS

1. Exit **all** positions  
2. Home **Close** or **Vault** tab → **Close vault**  
3. After status is Closed → **Unlock $1VAULTS**  

Details: [Close vault & unlock](/extension/close-vault-and-unlock).

---

## Investor path (park + ride)

1. Install + unlock wallet  
2. Bottom nav → **Discover**  
3. Search or pick an **Active** vault → open detail  
4. **Park SOL** into that vault  
5. Ride the shared book  
6. **Withdraw** anytime from Park → **My parks**, or wait for vault close (payout by share weight)  

Details: [Park into a vault](/investor/park-into-vault) / [Withdraw](/investor/withdraw).

---

## Mental model

> Strategist and investor park into the **same vault**. The strategist signs. The **vault** pays. Close is **by share weight**, not 50/50.

| Verb | Meaning |
|------|---------|
| **Park** | Deposit SOL for shares |
| **Sign** | Strategist authorizes a trade |
| **Ride** | Stay in the book while the strategist trades |
| **Close** | Wind down; settle by share weight; return $1VAULTS |
