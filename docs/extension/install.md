# Install the extension

The **1Vault** Chrome extension is how you use the product: wallet, create vault, park, trade, close, and unlock $1VAULTS.

## After you install

1. Pin **1Vault** in Chrome  
2. Open the **side panel**  
3. Create or import a wallet, then unlock with your password  
4. Continue with [Quick start](/guide/quick-start)

## What the extension can do

| You can… | Where |
|----------|--------|
| Create a vault and lock $1VAULTS | [Create vault & lock](/extension/create-vault-and-lock) |
| Park SOL | [Park SOL](/extension/park-and-capital) |
| Trade from the panel or GMGN | [Trade](/extension/trade-and-positions) / [Terminals](/extension/instant-trade-terminals) |
| Close the vault and unlock $1VAULTS | [Close & unlock](/extension/close-vault-and-unlock) |

## Permissions (plain language)

Chrome may ask for storage, side panel, and access to sites needed for trading and sign-in. You approve every transaction in the extension before it sends.
