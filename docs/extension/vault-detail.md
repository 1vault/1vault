# Vault detail

Open from Home (**Detail**) or a Discover card. Use **Back** to return.

## Overview

| Element | Meaning |
|---------|---------|
| Name + chips | Type (`POOLED` / `SLICED`), status (Active / Closed), verified `@handle` when linked |
| Large SOL NAV | Current vault value display |
| Stats | Return %, win rate, followers, estimated capital when available |
| Addresses | Vault address · trader address (short / copy) |
| CTA | **Park SOL** on someone else’s vault, or **Your vault** on your own |

Closed vaults may show a closed badge.

## Tabs

### Capital

Park breakdown: **My Park** / **Investor** / **Total**, plus wallet available when shown.

Empty: “Park breakdown unavailable.”

More: [Capital pipeline](/extension/capital-pipeline).

### Holdings

Who parked what (strategist / investors groups when indexed): deposited and remaining style rows.

Empty: “No holdings indexed yet.”

### Positions

Open positions for this vault. **Exit** is on the [Trade](/extension/trade-and-positions) tab - detail is for reading.

Empty: “No open positions.”

### Activity

Recent trades and fee activity (ids, status, amounts when available).

Empty: “No trades or fee activity yet.”

## Actions from detail

| Action | Result |
|--------|--------|
| **Park SOL** | Opens [Park](/extension/park-and-capital) for this vault |
| Back | Previous screen |
| Home Trade (after selecting vault) | Manage positions |

## Status tips

| Status | What it means for you |
|--------|------------------------|
| **Active** | Park / trade (strategist) allowed |
| **Closed** | No new parks; settlement done / in progress |
| Load error / not found | Wrong link or vault unavailable - go back to Discover / Home |
